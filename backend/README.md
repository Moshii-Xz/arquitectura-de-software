# Agro Inteligente Backend

Backend monolítico modular en Spring Boot para la plataforma de agricultura inteligente.

## Requisitos

- Java 17
- Maven 3.9+

## Ejecución local

```bash
mvn spring-boot:run
```

## Perfiles

- `dev`: H2 en memoria para arranque local rápido.
- `prod`: PostgreSQL con variables de entorno.
