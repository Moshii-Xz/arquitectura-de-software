# AgroInteligente Frontend

SPA funcional en React para materializar las vistas del proyecto.

## Como abrirlo

1. Abre `index.html` en un navegador moderno.
2. Navega entre vistas usando la barra superior o el sidebar.
3. Las rutas usan hash, por ejemplo `#/dashboard`, `#/cultivos` o `#/login`.

## Vistas incluidas

- Dashboard
- Cultivos
- Actividades
- Insumos
- Alertas
- Sincronizacion
- Perfil
- Login
- Login V2
- Registro exitoso
- Shell base

## Nota tecnica

Esta version no depende de Node ni Vite para poder ejecutarse en el entorno actual. Si luego quieres una version con build tooling, esta misma estructura se puede migrar a Vite sin cambiar el modelo visual.
